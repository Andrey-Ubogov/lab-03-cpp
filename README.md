## Часть 2. C++ (умные указатели)

## Тема проекта
**Симулятор умного дома**

Предметная область описывает виртуальный умный дом, в котором есть комнаты,
устройства и сценарии автоматизации. Пользователь может включать и выключать
устройства, ломать и чинить их, а также запускать сценарии, которые управляют
устройствами целой комнаты.

Эта часть — переработка проекта из ЛР 2. Логика и классы сохраняются, но все
обычные указатели заменены на умные: `std::unique_ptr`, `std::shared_ptr`,
`std::weak_ptr`. В проекте не остаётся ни одного `new` и ни одного `delete`.

## Классы и их ответственность

### 1. `Device` (Устройство)
**Ответственность:** описывает умное устройство внутри комнаты (лампа, телевизор, розетка).

**Поля (все private):**
- `m_name` — название устройства;
- `m_isOn` — включено ли устройство;
- `m_isBroken` — сломано ли устройство;
- `m_powerConsumption` — потребляемая мощность (Вт).

**Содержательные методы:**
- `TurnOn()` — включить устройство;
- `TurnOff()` — выключить устройство;
- `Break()` — сломать устройство;
- `Repair()` — починить устройство.

**Проверяемое правило предметной области:**
> Нельзя включить сломанное устройство.
> Проверка реализована в методе `TurnOn()`: если `m_isBroken == true`,
> выводится сообщение об ошибке, и состояние не меняется.

---

### 2. `Scenario` (Сценарий)
**Ответственность:** описывает сценарий автоматизации умного дома (например, «Утренний свет»).

**Поля (все private):**
- `m_name` — название сценария;
- `m_condition` — условие срабатывания (например, «07:00»);
- `m_isActive` — активирован ли сценарий.

**Содержательные методы:**
- `Activate()` — активировать сценарий;
- `Deactivate()` — деактивировать сценарий;
- `ChangeCondition(...)` — изменить условие срабатывания.

**Проверяемое правило предметной области:**
> Нельзя запустить неактивный сценарий.
> Проверка реализована в методе `Room::RunScenario()`: если сценарий не активирован
> или уже уничтожен, выводится сообщение об ошибке, и устройства не включаются.

---

### 3. `Room` (Комната)
**Ответственность:** объединяет устройства и использует сценарий для управления ими.

**Поля (все private):**
- `m_name` — название комнаты;
- `m_devices` — вектор устройств по значению (композиция);
- `m_scenario` — `std::weak_ptr<Scenario>` (агрегация).

**Содержательные методы:**
- `AddDevice(...)` — добавить устройство в комнату;
- `TurnOnAllDevices()` — включить все устройства;
- `TurnOffAllDevices()` — выключить все устройства;
- `SetScenario(...)` — привязать сценарий к комнате;
- `RunScenario()` — запустить сценарий.

## Связи между классами

### Композиция: `Room` → `Device`
**Что:** комната состоит из устройств.

**Почему композиция:** устройства не могут существовать без комнаты.
Комната сама создаёт их в конструкторе, и наружу они не отдаются.
Если уничтожить комнату, устройства исчезнут вместе с ней.

**В коде:** устройства хранятся как `std::vector<Device>` **по значению** —
это самый надёжный вид владения. Указатели здесь не нужны.
Задание прямо разрешает оставить это поле как есть:
«поле-объект по значению (композиция из ЛР 2) менять не нужно».

### Агрегация: `Room` → `Scenario`
**Что:** комната использует сценарий, но не владеет им.

**Почему агрегация:** сценарий создаётся снаружи (в `main`) и передаётся
готовым через `SetScenario`. Если уничтожить комнату, сценарий должен
продолжать существовать.

**В коде:** поле `m_scenario` — это `std::weak_ptr<Scenario>`.
`weak_ptr` не увеличивает счётчик владельцев и не продлевает жизнь объекту.
Перед использованием вызывается `lock()`, который возвращает `shared_ptr`:
пустой, если объект уже уничтожен.

## Сборка и запуск

### Требования
- Компилятор с поддержкой C++17 (Visual Studio 2019/2022, GCC 9+, Clang 10+).

### Сборка в Visual Studio
1. Открой файл `lab-03-spp.vcxproj` в Visual Studio.
2. Убедись, что в свойствах проекта:
   - **Компоновщик → Система → Подсистема** установлена в `Консоль (/SUBSYSTEM:CONSOLE)`.
3. Собери проект: **Сборка → Собрать решение** (или `Ctrl+Shift+B`).
4. Запусти: **Отладка → Запуск без отладки** (или `Ctrl+F5`).

### Сборка через командную строку (GCC/Clang)
```bash
g++ -std=c++17 -Wall -Wextra -o lab-03 main.cpp Device.cpp Scenario.cpp Room.cpp
./lab-03
